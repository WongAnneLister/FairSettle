# F28 · Complaint UI

## Goal

Behavior (copied from docs/features.json):

> A Gradio page submits a complaint for an order and shows the proposal status and a link to its trace.

Verification (copied from docs/features.json, `kind: manual`):

1. Submit a complaint from the page and see the proposal appear in the ledger console
2. Status updates after approval without a page reload error

Today a complaint can only be submitted through the agent's HTTP API, by curl or by the M2 script. F28 adds a small English Gradio page on `127.0.0.1:7860`. The page:

- calls the agent's API, and nothing else;
- shows the case's status and its proposal id;
- shows a summary of the decision: what was decided, how much, and who pays;
- links to the case's Langfuse trace;
- keeps the status current until the case is final.

### Decisions (user, 2026-11-02)

1. **English UI**, like the review page; the storefront stays Chinese.
2. **The page lives in the agent package and runs as its own service.**
   - The code is `fairsettle_agent/ui.py`, and `gradio==6.31.0` is added to the agent's dependencies.
   - The live overlay gains a `complaint-ui` service. It runs the same image with `python -m fairsettle_agent.ui` on `127.0.0.1:7860`.
   - The page talks to the agent only over HTTP. The cost is a larger agent image.
3. **The page shows a decision summary.** It shows the outcome, the decision, the amount, the reason and each party's basis points, besides the status, the proposal id and the trace link.
   - The agent's `GET /v1/complaints/{id}` gains a `decision` field for this, read from the graph state.
   - The field never carries the explanation, the evidence refs, the complaint text or an escalation's detail.
   - `POST` is unchanged.

Planner decisions (no user choice needed):
- **Complaint ids.** The page builds them as `ui-<16 hex chars>`, from `uuid4`. This matches `ComplaintInput`'s pattern and is never a reserved `delivery-failed-` id.
- **Complaint types.** The page offers `late_delivery`, `missing_item`, `wrong_item`, `quality` and `other`. `delivery_failed` is opened by the system (F25), not by a customer.
- **Polling.** A `gr.Timer` refreshes the status every `UI_POLL_SECONDS` (default 3). It stops once the status is final.
- **Waiting.** `POST /v1/complaints` is synchronous and can take minutes (F35: up to 5 model calls of up to 90 s). The page waits up to 660 s and shows Gradio's progress meanwhile.
- **No telemetry.** `GRADIO_ANALYTICS_ENABLED=False` is set in `main` and in compose, so the page makes no outside calls.
- **No authentication.** The page is bound to `127.0.0.1` for the demo. A public deployment must add authentication; that is F29's concern, and it is listed under Risks.

   ```python
   {"outcome": v["outcome"], "decision": d["decision"], "amount_cents": d["amount_cents"],
    "reason_code": d["reason_code"], "liability": [{"party": s["party"], "basis_points": s["basis_points"]} for s in d["liability"]],
   ```

3. Else, if `"escalation"` is in `values`, return `{"outcome": "escalate", "stage": e["stage"], "reason": e["reason"]}`, without `detail`.

### `agent/fairsettle_agent/ui.py` (new)

```python
"""English complaint page (Gradio) over the agent's HTTP API (F28)."""

COMPLAINT_TYPES = ("late_delivery", "missing_item", "wrong_item", "quality", "other")
FINAL = frozenset({"rejected", "declined", "escalated", "refunded", "refund_failed"})
SUBMIT_TIMEOUT_S = 660.0
LABELS = {
    "running": "Working on it", "submitting": "Sending the proposal", "submit_retry": "Sending the proposal",
    "awaiting_review": "Waiting for a reviewer", "approved": "Approved, refund in progress",
    "rejected": "Rejected by the agent", "declined": "Declined by a reviewer", "escalated": "Passed to a person",
    "refunded": "Refunded", "refund_failed": "Refund failed, a person will follow up",
}


@dataclass(frozen=True)
class UiConfig:
    agent_base_url: str
    trace_base_url: str | None
    host: str
    port: int
    poll_seconds: float

    @classmethod
    def from_env(cls, env: Mapping[str, str]) -> "UiConfig": ...


def new_complaint_id() -> str: ...
async def submit(http: httpx.AsyncClient, order_id: int, complaint_type: str, text: str) -> tuple[str | None, str]: ...
async def read_status(http: httpx.AsyncClient, complaint_id: str) -> dict | None: ...
def render(body: dict | None, trace_base_url: str | None) -> str: ...
def is_final(body: dict | None) -> bool: ...
def build_ui(config: UiConfig, client_factory: Callable[[], httpx.AsyncClient]) -> gr.Blocks: ...
def main(env: Mapping[str, str] = os.environ, launch: Callable[..., object] | None = None) -> None: ...
```

**`UiConfig.from_env`**

| Variable | Default | Rule |
| --- | --- | --- |
| `AGENT_BASE_URL` | `http://127.0.0.1:8000` | must start with `http://` or `https://`, else `ValueError("AGENT_BASE_URL must be an http(s) URL")` |
| `TRACE_BASE_URL` | unset → `None` | when set: must start with `http://` or `https://`; a trailing `/` is added if missing |
| `UI_HOST` | `127.0.0.1` | — |
| `UI_PORT` | `7860` | integer 1–65535, else `ValueError("UI_PORT must be an integer from 1 to 65535")` |
| `UI_POLL_SECONDS` | `3` | number 1–60, else `ValueError("UI_POLL_SECONDS must be a number from 1 to 60")` |

**`new_complaint_id`**: `"ui-" + uuid4().hex[:16]`.

**`submit`**
1. Validate before any request:
   - `order_id`: an `int` of at least 1 (Gradio gives a float for a number input; accept a float that is a whole number and convert it). Otherwise return `(None, "Enter an order number.")`.
   - `complaint_type` must be in `COMPLAINT_TYPES`. Otherwise return `(None, "Choose what went wrong.")`.
   - `text.strip()` must hold 1–4000 characters. Otherwise return `(None, "Describe the problem in up to 4000 characters.")`.
2. `POST /v1/complaints` with `{"complaint_id": new_complaint_id(), "order_id": order_id, "complaint_type": complaint_type, "text": text.strip()}` and `timeout=SUBMIT_TIMEOUT_S`.
3. Map the response:
   - 201 → `(complaint_id, "")`;
   - 409 → `(None, "This complaint was already sent.")`;
   - 422 → `(None, "The agent could not accept this complaint. Check the order number.")`;
   - any other status → `(None, f"The agent answered {status}. Try again later.")`;
   - an `httpx.HTTPError` → `(None, "The agent is not reachable. Try again later.")`.

   Never include the response body, or the exception's text, in the message.

**`read_status`**: `GET /v1/complaints/{id}` with a 10 s timeout. 200 → the JSON body; 404 → `None`. Any other status, or an `httpx.HTTPError`, raises nothing and returns `{"status": "unknown"}`.

**`render(body, trace_base_url)`** returns Markdown:
- `None` → `"No complaint yet."`
- Otherwise, in this order, separated by blank lines:
  1. `**Status:** <LABELS[status] or status>`
  2. `**Case:** \`<complaint_id>\``, plus `· **Proposal:** \`<proposal_id>\`` when it is set
  3. When `decision` is set:
     - for `outcome` `propose`, a line `**Decision:** <decision with "_" → " "> of $<amount_cents/100 with 2 decimals> for <reason_code with "_" → " ">`, then a line `**Who pays:** <party> <basis_points/100 with 0 decimals>%`, joined with `, `, skipping parties at 0;
     - for `reject`, `**Decision:** reject`;
     - for `escalate`, `**Decision:** passed to a person (<stage>: <reason with "_" → " ">)`, or without the parenthesis when `stage` is absent.
  4. When both `trace_base_url` and `trace_id` are set, `[Open the trace](<trace_base_url><trace_id>)`.

The text never contains the complaint text.

**`is_final(body)`**: `body is not None and body.get("status") in FINAL`. `None`, `"unknown"` and the other statuses are not final.

**`build_ui(config, client_factory)`**: a `gr.Blocks(title="FairSettle complaints")` containing:
- `gr.Markdown("# Report a problem with an order")`;
- `order = gr.Number(label="Order number", precision=0)`;
- `kind = gr.Dropdown(choices=list(COMPLAINT_TYPES), label="What went wrong", value="missing_item")`;
- `text = gr.Textbox(label="Describe the problem", lines=4, max_length=4000)`;
- `send = gr.Button("Send complaint", variant="primary")`;
- `notice = gr.Markdown("")`;
- `status = gr.Markdown(render(None, config.trace_base_url))`;
- `case = gr.State(None)`;
- `timer = gr.Timer(config.poll_seconds, active=False)`.

The handlers are async and open a client from `client_factory()` per call, in an `async with`:
- `send.click`: run `submit`. On success, set `case`, render `read_status` right away, and set `timer` active unless the status is already final. On failure, show the message in `notice` and leave the timer inactive.
- `timer.tick`: when `case` is set, read the status and render it. When `is_final`, set the timer inactive.

`main` uses `client_factory = lambda: httpx.AsyncClient(base_url=config.agent_base_url)`.

**`main`**
1. Set `os.environ.setdefault("GRADIO_ANALYTICS_ENABLED", "False")` before importing `gradio`. Import `gradio` at module top, after a module-level `os.environ.setdefault(...)` line placed before the import.
2. `config = UiConfig.from_env(env)`; `demo = build_ui(config, ...)`.
3. `(launch or demo.launch)(server_name=config.host, server_port=config.port)`. Call `demo.queue()` first, so long submissions run in the queue.

The module ends with `if __name__ == "__main__": main()`.

`ui.py` must not contain "paypal" (`tests/test_execute.py:155`), and it never imports `LedgerClient`.

## Out of scope

- Authentication, rate limits and public hosting (F29).
- Choosing an order from a list. The service token cannot list a customer's orders, and the page takes an order number.
- The storefront's link to this page, and the storefront's `DeliveryFailed` label.
- Showing the model's explanation or evidence; editing or withdrawing a complaint.

## Risks

- **No authentication.** Anyone who can reach port 7860 can file complaints for any order number. The bind is `127.0.0.1` for the demo; F29 must add authentication before going public.
- **Long submissions.** A `POST` can take minutes; Gradio's queue and the 660 s timeout cover it. If the agent restarts mid-call, the page shows "The agent is not reachable", and the case may still exist. Its id was not shown, so the person sends again with a new id; the ledger's refundable amount prevents a double refund.
- **Image size.** `gradio` adds 18 packages, `numpy`, `pandas` and `pillow` among them, so the agent image grows by a few hundred MB.
- **Gradio behaviour across versions.** The version is pinned to 6.31.0. If `gr.Timer(active=...)` or the `.tick` event behaves differently at runtime from the probe, stop and report.
